# The Ramsey community number as a renormalization-group crossing

Reproducibility package for the manuscript

> **The Ramsey community number as a renormalization-group crossing**

submitted to *Physica A: Statistical Mechanics and its Applications*
(Elsevier `elsarticle`, `preprint,12pt`). Third in
the "wants to be broken" series, after the ring and the pseudofractal web.

## What is shown

On the diamond hierarchical lattice (the `(b,s)=(2,2)` Migdal–Kadanoff cell,
equivalently the `(2,2)`-flower) the Ramsey community number `r_κ` is an **exact
renormalization-group threshold crossing** rather than a fitted slope:

* the block-pair sufficient statistics of the self-similar bundle cut obey an
  exact **linear** RG map `M` with spectrum `{λ_vol, λ_seam} = {bs, b}`
  (volume rate `bs`, seam rate `b`; gap `1/s`);
* the degree-corrected block-model evidence flows to a community fixed point
  `(u_in, u_cross) = (K, 0)` with evidence density `log R_dc / m → ln K`
  (lattice-independent; cross-checked against the pseudofractal 3-way cut);
* `r_κ` is the generation at which the running evidence crosses
  `ln[q/(1−q)]`: `r_κ = 12` (q=0.5) and `44` (q≥0.9). A closed form
  `r_κ(b,s;q)` is derived for the whole family, with an explicit finite-size
  correction and an explicit statement of when the closed form is exact.
* plain and degree-corrected detection differ only by `O(ln m)` once both are
  conditioned on the same partition: the apparent gap (`44` vs `684`) is the
  node-labelling prior `Λ_t → −n ln K`, and the density ratio between the two
  prior conventions is `(1 − n/m)^{-1}` (`3` here, `2` for a lattice with
  `n/m → 1/2`).

The paper then places two spin models on the same lattice and shows the
community partition is not merely detectable but **thermodynamically ordered**:

* the `K=2` Reichardt–Bornholdt Hamiltonian has an exact community-ordered
  phase — below the ferromagnetic critical temperature (`k_B T_c/J = 1.641`)
  the two hubs lock into opposite communities for any resolution `γ>0`, and the
  order persists as `n→∞`. The ordered state is the *staggered* cut (one hub
  per block), which beats the bundle cut by exactly `γ` at every size;
* the optimal partition is a nested hierarchy cut at half the depth of the
  lattice, `d_⋆ = t/2`, i.e. `K_opt = √γ · m^{1/4} ∼ n^{1/4}` communities, so
  the number of Potts states that best describes the network grows with the
  network;
* that hierarchy stays thermally rigid level by level. The transition is
  **continuous for every `K`** (no latent heat; the step in the order parameter
  is a finite-size crossover of width `λ_T^{-t}`), and the ordering temperature
  falls as `k_B T_c/J → 3/(2 ln K)`, an exact asymptote.

## Reproduce

Requirements: Python 3 with `numpy`, `networkx`, `mpmath`, `matplotlib`; a TeX
Live installation including Elsevier `elsarticle` (Debian/Ubuntu package
`texlive-publishers`).

```sh
pip install numpy networkx mpmath matplotlib
make verify     # prints all tables, slopes, the RG map spectrum, and r_kappa
make            # regenerates the five figures and compiles manuscript.pdf
```

Running `python3 diamond_rg.py` alone reproduces, from scratch and checked
against direct construction of the lattice through `t=7`: the closed-form
block-pair counts, the exact RG map and its eigenvalues `{bs, b}`, the evidence
of both models in both prior conventions (Tables I–IV), the density fixed point
`ln K` with its analytic deficit, the density flow, and the Ramsey numbers. All arithmetic is at 80 digits (`mpmath`).

## Notes

* **Author / affiliation** are carried over from the companion papers and should
  be finalized before submission.
* The lattice exists only at discrete sizes `N_t = (2·4^t + 4)/3`, so `r_κ` is
  necessarily one of these values.
* The `(b,s)` generalization: `diamond(t, b, s)` in `diamond_rg.py` builds the
  general lattice; `probe_bs.py` verifies `λ_vol = bs`, `λ_seam = b` for
  `(b,s) ∈ {(2,2),(3,2),(4,2),(2,3),(2,4),(3,3)}`.
